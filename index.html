Project guide

프로젝트가이드

프로젝트 운영 규칙, Git 사용법, 브랜치 전략, 배포 방법을 한곳에서 관리합니다. 이 탭은 사용자의 프로젝트가이드 Git 저장소와 연결됩니다.

프로젝트가이드 Git 열기 ↗
01 · 저장소 확인조별 저장소와 작업 범위를 확인합니다.
02 · 작업 규칙브랜치·커밋·Pull Request 규칙을 따릅니다.
03 · 배포 확인main 반영 후 담당 서브도메인에서 결과를 확인합니다.
Central project hub · Git repository and deployment links are managed centrally.

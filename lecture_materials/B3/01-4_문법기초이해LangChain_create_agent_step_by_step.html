첫 질문: invoke()

STEP 04 / 10

@tool 선언과 tools 연결

도구는 @tool 함수로 만들거나 적절한 시그니처와 설명을 갖춘 함수를 직접 전달할 수 있습니다.

따라하기 코드

Python · 복사 후 실행
from langchain.agents import create_agent
from langchain.tools import tool

@tool
def multiply(a: int, b: int) -> int:
    """두 정수를 곱한 값을 반환한다."""
    return a * b

agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[multiply]
)

result = agent.invoke({"messages": [
    {"role": "user", "content": "13 곱하기 7은? 계산 도구를 사용해줘."}
]})
print(result["messages"][-1].content)
# 모델이 도구 호출 여부를 결정합니다.

messages와 HumanMessage

입력은 메시지 딕셔너리 또는 HumanMessage 객체로 전달할 수 있습니다. 응답에는 AIMessage와 도구 실행 시 ToolMessage가 포함될 수 있습니다.

따라하기 코드

from langchain_core.messages import HumanMessage

agent = create_agent("openai:gpt-4.1-mini", tools=[])

result = agent.invoke({
    "messages": [HumanMessage(content="RAG를 한 줄로 설명해줘")]

for msg in result["messages"]:
    print(type(msg).__name__, msg.content)

STEP 07 / 10

도구 호출 내부 흐름

LLM이 tool_calls를 생성하면 에이전트가 도구를 실행하고 ToolMessage 결과를 다시 모델에 전달합니다. 모델이 더 이상 도구 호출을 요청하지 않을 때 종료합니다.

따라하기 코드

Python · 복사 후 실행
from langchain.agents import create_agent
from langchain.tools import tool

@tool
def get_policy(item: str) -> str:
    """상품 종류별 환불 규정을 조회한다."""
    return "냉장식품은 단순변심 반품 불가, 오배송은 접수 가능"

agent = create_agent("openai:gpt-4.1-mini", tools=[get_policy])
result = agent.invoke({"messages": [
    {"role": "user", "content": "냉장식품 오배송이면 반품할 수 있나요? 도구로 확인해줘."}
]})

for m in result["messages"]:
    print(type(m).__name__, m.content)
# AIMessage(tool_calls) → ToolMessage → AIMessage 순서가 보일 수 있습니다.
이해도 확인 07

도구 실행 결과를 담는 메시지는?

STEP 08 / 10

stream()으로 과정 관찰

stream_mode="updates"를 사용하면 모델/도구 노드별 상태 변화를 순차적으로 관찰할 수 있습니다.

따라하기 코드

Python · 복사 후 실행
from langchain.agents import create_agent
from langchain.tools import tool

@tool
def add(a: int, b: int) -> int:
    """두 정수를 더한다."""
    return a + b

agent = create_agent("openai:gpt-4.1-mini", tools=[add])

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "15와 27을 더해줘. 도구 사용."}]},
    stream_mode="updates"
):
    print(chunk)

STEP 09 / 10

체크포인터와 대화 기억

checkpointer를 사용하고 같은 thread_id로 실행하면 이전 상태를 이어갈 수 있습니다. InMemorySaver는 실습용이며 프로세스를 종료하면 사라집니다.

따라하기 코드

Python · 복사 후 실행
from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[],
    checkpointer=InMemorySaver()
)
config = {"configurable": {"thread_id": "student-01"}}

agent.invoke({"messages": [
    {"role": "user", "content": "내가 좋아하는 언어는 파이썬이야."}
]}, config=config)

result = agent.invoke({"messages": [
    {"role": "user", "content": "내가 좋아하는 언어는?"}
]}, config=config)
print(result["messages"][-1].content)

STEP 10 / 10

종합 실습: 쇼핑몰 FAQ 에이전트

@tool, create_agent, system_prompt, invoke를 하나로 합칩니다. 실제 서비스에서는 FAQ 데이터 조회나 DB 검색으로 교체할 수 있습니다.

따라하기 코드

Python · 복사 후 실행
from langchain.agents import create_agent
from langchain.tools import tool

FAQ = {
    "배송": "일반 배송은 결제 후 2~3영업일입니다.",
    "환불": "일반 상품은 수령 후 7일 이내 신청 가능합니다.",
}

@tool
def search_faq(category: str) -> str:
    """쇼핑몰 FAQ를 카테고리(배송/환불)로 조회한다."""
    return FAQ.get(category, "해당 FAQ가 없습니다.")

agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[search_faq],
    system_prompt="쇼핑몰 상담원이다. 정책 질문은 search_faq로 확인하고, 근거 없는 답은 만들지 마라."
)

result = agent.invoke({"messages": [
    {"role": "user", "content": "일반 상품 환불 신청 기간이 며칠인가요? FAQ를 조회해줘."}
]})
print(result["messages"][-1].content)
# 심화: print([type(m).__name__ for m in result["messages"]])

웹 접근성 정합성 검사는 실무형 학습을 위한 공통 문제이며, 최종 목표는 규칙 기반 자동화·정보검색·RAG (Retrieval-Augmented Generation)·에이전트·로컬 모델·문서 처리를 하나의 서비스로 구현하고 운영하는 것입니다.

공통 설계

평가 기준과 정답셋

평가는 A1에서 시작하며 같은 테스트 사례와 근거 문서를 재사용합니다. 단, 이후 문서·에이전트 기능이 늘어나면 해당 평가셋을 확장합니다.

평가 대상지표판단 질문
위반 탐지Precision / Recall / F1 (F1 score) / 혼동행렬위반을 정확히 찾았는가?
근거 검색Recall@k (Recall at k) / MRR (Mean Reciprocal Rank) / nDCG (normalized Discounted Cumulative Gain)올바른 조항·기법이 상위에 검색되는가?
RAG (Retrieval-Augmented Generation) 생성인용 정확도 / faithfulness / 답변 관련성찾은 근거에 충실한 설명인가?
에이전트작업 성공률 / 도구 경로 / 오류 복구율필요한 도구를 올바르게 사용했는가?
PDF (Portable Document Format)·OCR (Optical Character Recognition)CER (Character Error Rate) / WER (Word Error Rate) / 추출·검색 정확도추출 과정의 오류가 검색·판정에 영향을 주는가?
서비스 운영p95 (95th percentile) / 오류율 / 캐시 적중률 / 비용운영 환경에서도 안정적으로 작동하는가?

주의: W3C (World Wide Web Consortium) Validator의 HTML (HyperText Markup Language) 문법 검출과 WCAG (Web Content Accessibility Guidelines) 접근성의 정답은 같지 않습니다. 정답셋은 표준 근거와 맥락 검토를 통해 확정합니다.

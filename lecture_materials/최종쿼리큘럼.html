가비아 서버에서 VM 내부 MySQL 주소에 바로 접근된다고 전제하지 않습니다. 실제 운영 DB 배치 또는 안전한 네트워크 연결을 먼저 검증합니다. HPA는 Pod 수를 조절할 뿐 노드 용량을 늘리지 않으며, 유료 LLM 호출 부하 테스트는 Mock 응답으로 대체합니다. 학생별 도메인 설계는 이번 커리큘럼의 범위에 포함하지 않습니다.

운영 배포 관문: Git 이미지 태그와 별도로 MySQL 스키마 버전·벡터 색인 버전·임베딩 모델을 기록한다. 신규 색인은 사전 검증 후 전환하며 애플리케이션 롤백이 데이터 롤백을 의미하지 않음을 검증한다.

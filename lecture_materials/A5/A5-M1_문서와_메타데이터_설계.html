# 냉장식품 반품·품질 예외

## 개요
이 정책은 생크림 케이크, 요거트, 신선 연어처럼 냉장 상태로 배송되는 냉장식품의 반품과 품질 이상 처리 기준을 정한다. 냉장식품은 받은 뒤 보관 상태에 따라 품질이 바뀌므로, 일반상품처럼 단순 변심 반품을 받지 않는다. 대신 품질에 문제가 생긴 경우를 짧은 기한 안에 접수받아 증빙으로 판단한다.

## 업무 규정
냉장식품은 단순 변심 반품이 원칙적으로 불가하다. 오배송·변질·온도 이탈·판매자 귀책 배송 지연으로 인한 품질 훼손은 수령 후 48시간 안에 접수하고 증빙을 확인해 환불 또는 재배송한다. 단순히 제주 지역이라는 이유만으로 자동 환불하지 않는다.

## 처리 절차
1. 고객이 품질 이상을 알리면 수령 시각과 접수 시각을 기록하고, 수령 후 48시간 안에 접수됐는지 확인한다.
2. 변질, 온도 이탈, 오배송, 판매자 귀책 배송 지연 중 어떤 사유인지 구분한다.
3. 상품 사진, 보관 상태, 온도 기록을 받아 실제 품질 훼손이 있었는지 확인한다.
4. 품질 훼손이 확인되면 환불 또는 재배송 중 하나로 처리한다.
5. 배송비 환불이 함께 요청되면 품질 확인이 끝난 뒤 배송비 정책에 따라 따로 판단한다.

## 적용 예시
- 10월 주문의 냉장식품을 받고 36시간 뒤 변질을 신고했다 → 48시간 안이므로 시간 요건은 충족한다. 실제 변질 여부는 사진과 온도 기록으로 검증한다.
- 받은 지 48시간이 지나서 변질을 신고했다 → 접수 기한을 넘겼다.
- 포장을 열어 보니 주문하지 않은 다른 냉장식품이 왔다(오배송) → 기한 안에 접수하면 환불 또는 재배송을 검토한다.
- 맛이 생각과 달라 반품하고 싶다(단순 변심) → 냉장식품은 단순 변심 반품이 원칙적으로 불가하다.
- 제주로 배송돼 늦게 도착했지만 온도 기록과 상품 상태가 정상이다 → 제주 지역이라는 이유만으로 자동 환불하지 않는다.

## 확인 항목 및 주의
수령시각, 접수시각, 보관 상태, 사진과 온도 기록을 비교한다. 품질 확인 전 배송비 환불을 보장하지 않는다.

## 자주 혼동하는 경우
- 일반상품의 수령 후 7일 반품 기준을 냉장식품에 적용하지 않는다.
- 늦게 도착했다는 사실과 품질이 훼손됐다는 사실은 별개다. 지연만으로 환불을 약속하지 않는다.
- 제주 지역 냉장식품의 지연과 배송비 문제는 제주 냉장식품 예외 지침을 함께 확인한다.
- 주문일이 이전 정책 기간에 속하면 접수 기한이 다를 수 있으므로 주문일을 먼저 확인한다.

3. POL과 EXC — 기본 정책과 예외 규정

구분의미분류 기준
POLPolicy (기본 정책)일반적인 업무 처리 기준과 규정
EXCException (예외 규정)특정 조건에서 기본 정책과 다르게 적용되는 규정

EXC는 별도의 FAQ가 아니라, 기본 정책의 적용 범위를 제한하거나, 조건에 따라 다른 처리 방법을 지정하는 규정입니다. 실제 짝 하나의 업무 규정을 나란히 보세요.

POL-CAN-002(기본)와 EXC-004(예외)
POL-CAN-002.md · 업무 규정
주문제작 상품은 제작 착수 전 취소가 가능하다. 제작이 시작된 뒤 단순 변심 취소는 제한되며 파손·오제작·계약 불일치 등 판매자 책임 사유는 별도 조사한다. 상품준비중이라는 표시가 반드시 제작착수 전을 의미하지는 않는다.
EXC-004.md · 업무 규정 + 확인 항목
제작 시작 후라도 오제작·파손·사양 불일치가 확인되면 단순 변심과 달리 판매자 귀책으로 검토한다. 제작이 시작되었다는 이유 하나로 모든 환불을 거절하지 않는다. 사양 승인 기록, 제작 착수시각과 문제 사진을 확보한다.

적용 정책: POL-CAN-002, POL-FEE-001. 일반상품 7일 반품 규정을 자동 적용하지 않는다.
보이는 것

기본 정책 POL-CAN-002는 “제작이 시작된 뒤 단순 변심 취소는 제한”입니다. 예외 EXC-004는 “그래도 오제작 · 파손이면 판매자 귀책으로 검토”라고 처리를 바꿉니다. 그리고 “적용 정책: POL-CAN-002 …” 줄로 어느 기본 정책에 붙는 예외인지 밝힙니다.

def read_csv(path):
    with open(path, encoding="utf-8-sig", newline="") as f:  # BOM이 있는 CSV
        return list(csv.DictReader(f))


def load_faq():
    docs = []
    for r in read_csv(DATA / "faq.csv"):
        docs.append({"id": r["doc_id"], "kind": "faq", "title": r["question"],
                     "text": f"질문: {r['question']}\n답변: {r['answer']}",
                     "meta": {k: r[k] for k in META_FIELDS},
                     "links": [x for x in r["related_policy_ids"].split("|") if x]})
    return docs


def load_policies():
    docs = []
    for r in read_csv(DATA / "policies.csv"):
        text = (DATA / r["file"]).read_text(encoding="utf-8")  # 목록의 링크를 따라 본문을 읽는다
        docs.append({"id": r["doc_id"], "kind": "policy", "title": r["title"], "text": text,
                     "meta": dict({k: r[k] for k in META_FIELDS}, doc_type=r["doc_type"]),
                     "links": []})
    return docs


def load_all():
    return load_faq() + load_policies()

def normalize(text):
    """유니코드 NFC + 줄 끝 공백 제거 + 빈 줄 여러 개를 하나로. 줄바꿈(마크다운 구조)은 남긴다."""
    text = unicodedata.normalize("NFC", text)
    text = "\n".join(line.rstrip() for line in text.splitlines())
    return re.sub(r"\n{3,}", "\n\n", text).strip()


def flatten(text):
    """글자 수로 자를 때 쓰는 한 줄 텍스트: 모든 공백을 한 칸으로."""
    return re.sub(r"\s+", " ", normalize(text)).strip()


def chunk_by_section(doc):
    """마크다운 '## 소제목' 단위로 자른다. 각 조각 앞에 '문서 제목 > 소제목'을 붙인다."""
    text = normalize(doc["text"])
    parts = re.split(r"\n(?=## )", text)
    title = parts[0].lstrip("# ").splitlines()[0]
    chunks = []
    for part in parts[1:]:
        head, _, body = part.partition("\n")
        section = head.lstrip("# ").strip()
        chunks.append({"section": section, "text": f"{title} > {section}\n{body.strip()}"})
    return chunks


def chunk_by_chars(doc, size=300, overlap=50):
    """글자 수 창으로 자른다. 다음 창은 (size - overlap) 뒤에서 시작한다."""
    text = flatten(doc["text"])
    step, start, chunks = size - overlap, 0, []
    while start < len(text):
        chunks.append({"section": f"{start}~{min(start + size, len(text))}자", "text": text[start:start + size].strip()})
        if start + size >= len(text):
            break
        start += step
    return chunks
  1. normalize: 유니코드를 NFC로 맞추고(같은 한글이 다른 코드로 저장된 경우 대비), 줄 끝 공백과 연속된 빈 줄을 정리합니다. 줄바꿈은 남깁니다 — 마크다운 구조이기 때문입니다.
  2. chunk_by_section: ## 소제목 앞에서 자릅니다. 조각 맨 앞에 문서 제목 > 소제목을 붙여, 조각만 봐도 어디서 왔는지 알게 합니다.
  3. chunk_by_chars: 모든 공백을 한 칸으로 만든 뒤 size글자씩 자릅니다. 다음 조각은 size - overlap글자 뒤에서 시작해, 경계의 overlap글자가 두 조각에 함께 들어갑니다.

def grams(text):
    t = flatten(text)
    return [t[i:i + 2] for i in range(len(t) - 1) if " " not in t[i:i + 2]]


class KeywordSearch:
    """질문과 겹치는 2글자 조각이 많고, 그 조각이 드물수록 점수가 높다."""

    def __init__(self, chunks):
        self.chunks = chunks
        self.tf = [Counter(grams(c["text"])) for c in chunks]
        df = Counter(g for tf in self.tf for g in tf)
        self.idf = {g: math.log(1 + len(chunks) / n) for g, n in df.items()}

    def scores(self, query):
        q = set(grams(query))
        return [sum(min(tf[g], 3) * self.idf[g] for g in q if g in tf) / math.sqrt(sum(tf.values()) + 1) for tf in self.tf]

    def search(self, query, k=5, allow=None, boost=None):
        """allow: 조각 → True/False (필수 조건, 통과한 조각만 남김)
        boost: 조각 → 배수 (선택 조건, 점수만 올림. 거르지는 않음)"""
        sc = self.scores(query)
        if boost:
            sc = [s * boost(c) for s, c in zip(sc, self.chunks)]
        order = sorted(range(len(self.chunks)), key=lambda i: -sc[i])
        hits = [self.chunks[i] for i in order if sc[i] > 0 and (allow is None or allow(self.chunks[i]))]
        return hits[:k]


def match(meta, conditions, wildcard=True):
    """conditions: {"열": "값" 또는 ["값", ...]}. wildcard=True면 문서 값이 '전체'일 때도 통과."""
    for field, want in conditions.items():
        want = [want] if isinstance(want, str) else want
        ok = meta.get(field) in want or (wildcard and meta.get(field) == WILDCARD)
        if not ok:
            return False
    return True

def find_links(text):
    """정책 본문의 '적용 정책: ...' 줄에 적힌 문서 ID."""
    m = re.search(r"적용 정책: ([^.\n]*)", text)
    return ID_PATTERN.findall(m.group(1)) if m else []


def follow_links(hits, policies_by_id):
    """결과 조각이 가리키는 정책(FAQ의 related_policy_ids, 정책 본문의 '적용 정책')을 모은다."""
    found = []
    for h in hits:
        if h["kind"] == "faq":
            targets = h["links"]                                          # FAQ → 열에 적힌 정책
        else:
            targets = find_links(policies_by_id[h["doc_id"]]["text"])     # 정책 → 본문의 '적용 정책'

        for t in targets:
            if t not in found:
                found.append(t)
    return found

  2. follow_links: 결과 조각이 FAQ면 related_policy_ids 열을, 정책이면 본문의 ‘적용 정책’을 따라갑니다. 이것이 연결 1번입니다.
  3. m1_03_search.py는 연결 1번으로 새로 들어온 정책의 ‘적용 정책’을 한 번 더 따라갑니다. 이것이 연결 2번입니다.

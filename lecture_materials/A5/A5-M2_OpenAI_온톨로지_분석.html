01. 이름으로만 적힌 연결 — 문장 속에 숨은 관계

POL 문서끼리도 실제로는 이어져 있습니다. ID 대신 이름으로 적혀 있을 뿐입니다.

POL 문서에는 다른 문서의 ID가 없습니다. 그런데 본문을 읽어 보면 다른 정책을 가리키는 문장이 있습니다. POL-RET-001.md의 마지막 소제목입니다.

dataset/md/POL-RET-001.md
## 자주 혼동하는 경우
- 출고 전 주문 취소는 반품이 아니라 취소 절차를 따른다.
- 배송 중인 상품을 취소하려는 경우는 즉시 취소가 아니라 회수와 반품 절차를 확인해야 한다.
- 냉장식품의 품질 이상은 7일 기준이 아니라 냉장식품 품질 예외 정책의 접수 기한을 따른다.
- 주문제작 상품은 제작 단계에 따라 기준이 달라지므로 이 정책의 7일 반품 규정을 자동으로 적용하지 않는다.

    """OpenAI에 JSON 응답을 요청하고, 요청과 응답을 outputs_m2/raw/<name>.json에 저장한다."""
    RAW.mkdir(parents=True, exist_ok=True)

    if dry_run:
        print(f"[dry-run] {name} · 모델 {MODEL}\n--- system ---\n{system}\n--- user ---\n{user}\n")
        return None
    if path.exists() and not refresh:

    from openai import OpenAI  # pip install openai

    client = OpenAI(api_key=os.environ["OPENAI_API_KEY"])
    kwargs = {"model": MODEL, "response_format": {"type": "json_object"},
              "messages": [{"role": "system", "content": system}, {"role": "user", "content": user}]}
    if MODEL.startswith("gpt-4"):

    resp = client.chat.completions.create(**kwargs)
    text = resp.choices[0].message.content
    record = {"name": name, "model": resp.model, "seconds": round(time.time() - t0, 1),

    path.write_text(json.dumps(record, ensure_ascii=False, indent=2), encoding="utf-8")

## 개요
이 지침은 제주로 배송되는 냉장식품이 약속한 날짜보다 늦게 도착했을 때 상품대금과 배송비를 어떻게 처리할지 정한 예외 규정이다. 제주는 항공편이나 선박을 거쳐야 해서 기상과 운송 일정의 영향을 크게 받고, 냉장식품은 시간이 지나면 품질이 변할 수 있다. 두 조건이 겹치므로 일반 배송 지연이나 일반상품 반품 기준만으로 판단하지 않고 이 지침을 함께 적용한다.

## 업무 규정
제주 냉장식품에 배송지연이 발생해도 자동 환불되지 않는다. 주문 약정일·실제 출고시각·기상 영향·온도 이탈을 확인한다. 판매자 귀책 지연으로 품질 훼손이 확정되면 상품대금과 실제 결제한 기본배송비·추가배송비를 함께 검토한다. 항공편 중단 같은 외부 요인은 판매자 귀책 판단을 보류할 수 있다.

def section_of(doc, quote):
    """근거 문장이 들어 있는 '## 소제목'을 찾는다. 원문에 없으면 None"""
    q = squash(quote)
    if not q:
        return None
    sec = "(머리)"
    for line in normalize(doc["text"]).splitlines():
        if line.startswith("## "):
            sec = line[3:].strip()
        elif q in squash(line):
            return sec
    return None

근거 문장이 ‘있다’와 근거가 ‘된다’는 다르다

0.3의 함께적용 중 EXC-001 → POL-DEL-002 · POL-RET-002 · POL-FEE-001 세 개는 근거가 ‘개요’의 “일반 배송 지연이나 일반상품 반품 기준만으로 판단하지 않고 이 지침을 함께 적용한다.”입니다. 문장은 원문에 있어 검사를 통과했지만, 이 문장에는 세 문서의 이름이 없습니다. 관계 자체는 맞지만(‘적용 정책:’ 줄에도 있음) 근거로 든 문장이 그 관계를 말하지는 않습니다. 코드 검사는 ‘문장이 원문에 있는가’까지만 확인하므로, 중요한 관계는 사람이 근거를 읽어 확인합니다.
